# CodeLearn — изучение языков программирования

Кроссплатформенное приложение (Windows, macOS, Linux, Android и браузер) для изучения **Python, C#, C++, Java, JavaScript и 1С** с нуля до уровня Middle, а также основ **Arduino и ESP32**.

- 📖 Теория с подсветкой кода
- ✍️ 5 типов интерактивных заданий: тест (один или несколько ответов), «что выведет код», заполнение пропусков, сборка кода из строк, поиск строки с ошибкой
- 🏠 Домашние задания: подсказки, самопроверка по чек-листу, эталонное решение, решение сохраняется
- 🔁 Повторение ошибок (задания, в которых вы ошиблись, собираются в отдельный раздел)
- ⭐ XP, уровни, серия дней подряд, прогресс по курсам
- 🌙 Тёмная и светлая темы, поиск уроков, экспорт/импорт прогресса
- 📴 Работает полностью офлайн, без регистрации и сервера

## Arduino и ESP32 (версия 1.1.0)

Новые курсы содержат по 12 готовых уроков: теория, 5 интерактивных заданий и домашняя работа с примером решения. Поиск, XP, повторение ошибок и сохранение прогресса используют существующий механизм приложения. Идентификаторы прежних курсов и ключ хранилища не изменены.

- **Arduino:** Uno R3 / ATmega328P, Arduino IDE, GPIO, кнопки, ADC, PWM, millis, дребезг, Serial, I2C, прерывания, EEPROM, проект светильника.
- **ESP32:** классическая ESP32-WROOM-32 DevKit, **Arduino-ESP32 3.x**, GPIO, ADC1, LEDC, Wi-Fi, HTTP, MQTT, BLE, deep sleep, Preferences/NVS, FreeRTOS, Wi-Fi панель LED.
- Для MQTT установите PubSubClient через менеджер библиотек Arduino IDE и используйте свой локальный брокер. Остальные примеры используют библиотеки выбранного ядра.
- **CodeLearn не компилирует код и не эмулирует платы.** Для загрузки скетчей нужны Arduino IDE и оборудование. Все интерактивные задания доступны без платы.
- GPIO ESP32 допускают 3,3 В, не 5 В. Подключайте LED через резистор, собирайте схемы без питания. Сетевое напряжение и силовые нагрузки не входят в курсы.
- Уроки не заявляют совместимость со всеми моделями Uno/ESP32; для C3/S3, Uno R4 и других плат потребуется адаптация.

Проверка контента после изменений:

```bash
npm run content
npm run test:embedded
```

Подробнее о схемах и запуске: [docs/EMBEDDED_GUIDE.md](docs/EMBEDDED_GUIDE.md).

## Быстрый старт (без установки)

Откройте `www/index.html` в браузере — приложение запустится сразу.

## Сборка приложений

> 📘 **Подробный пошаговый гайд для новичков: [docs/BUILD_GUIDE.md](docs/BUILD_GUIDE.md)** — EXE-установщик, APK, подпись релиза, публикация и решение типичных ошибок.

Нужен [Node.js 20+](https://nodejs.org).

```bash
npm install
```

### 💻 Десктоп (Electron)

```bash
npm start            # запуск в окне
npm run dist:win     # установщик Windows (.exe) → папка dist/
npm run dist:linux   # AppImage и .deb
npm run dist:mac     # .dmg (собирается только на macOS)
```

### 📱 Android (Capacitor)

Нужны [Android Studio](https://developer.android.com/studio) и JDK 17.

```bash
npm run android:init   # один раз: создаёт папку android/ и ставит иконки
npm run android:sync   # после каждого изменения в www/
npm run android:open   # открыть в Android Studio → Run ▶ или Build → Build APK
```

### ☁️ Сборка в облаке без установки SDK (рекомендуется)

1. Создайте репозиторий на GitHub и загрузите туда проект.
2. Откройте вкладку **Actions**: workflow `Build apps` запустится сам.
3. Через ~10 минут в разделе **Artifacts** появятся: `.apk` для Android, `.exe` для Windows, `.AppImage`/`.deb` для Linux, `.dmg` для macOS.

### 🌐 Как веб-приложение (PWA)

```bash
npm run web   # http://localhost:8080
```

Разместите папку `www/` на любом хостинге (GitHub Pages, Netlify), и приложение можно будет установить на телефон или компьютер из браузера.

## Публикация в Google Play

1. Android Studio → **Build → Generate Signed Bundle / APK → Android App Bundle**, создайте ключ (keystore). Храните его надёжно: без ключа нельзя выпускать обновления.
2. Зарегистрируйте аккаунт разработчика в [Google Play Console](https://play.google.com/console) (разовый взнос $25).
3. Создайте приложение, загрузите `.aab`, заполните описание, скриншоты, политику конфиденциальности (приложение не собирает данные: всё хранится на устройстве) и возрастной рейтинг.
4. Новые личные аккаунты должны пройти закрытое тестирование: 12+ тестировщиков в течение 14 дней.
5. Перед каждым выпуском увеличивайте `versionCode` в `android/app/build.gradle`.

## Как добавлять уроки

Весь контент хранится в YAML-файлах в папке `content/` (по одному файлу на язык). После изменений выполните:

```bash
npm run content   # проверяет контент и собирает www/data/content.js
```

Скрипт сам проверит ошибки: неверный индекс ответа, число пропусков, дубликаты id.

Урок, который ещё не написан, — это просто строка с названием (в приложении показывается как «скоро»). Готовый урок:

````yaml
- id: py-03-01                 # уникальный id
  title: Определение функций
  minutes: 20
  xp: 25
  theory: |
    Markdown-текст. Код — в блоках ```python ... ```
  practice:
    - type: choice             # тест
      q: Вопрос?
      options: ["вариант 0", "вариант 1"]
      answer: 1                # или [0, 1] — несколько правильных
      explain: Пояснение (необязательно)
    - type: output             # что выведет код
      q: Что выведет код?
      code: |
        print(2 + 2)
      answer: "4"              # или список допустимых ответов
    - type: fill               # пропуски ___ в коде
      q: Допишите код
      code: |
        ___ greet():
      answers: [def]           # для каждого пропуска; можно [[a, b]] — варианты
    - type: order              # собрать строки в порядке
      q: Соберите программу
      lines: ["строка 1", "строка 2"]
    - type: bug                # найти строку с ошибкой
      q: Где ошибка?
      code: |
        x = 1
        print(X)
      bugLine: 2
      fix: print(x)
  homework:
    task: Текст задания (Markdown)
    hints: ["подсказка"]
    checklist: ["критерий самопроверки"]
    solution: |
      эталонный код
````

> Совет: если значение в YAML содержит `: ` или начинается с `` ` ``, возьмите его в кавычки. `python3 tools/fix-yaml.py content/*.yaml` сделает это автоматически.
