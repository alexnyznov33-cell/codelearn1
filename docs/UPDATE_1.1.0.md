# Обновление CodeLearn 1.1.0

## Изменения

- Два новых курса: Arduino и ESP32. Каждый: 4 модуля, 12 готовых уроков, 60 заданий, 12 домашних работ с решениями.
- Все пять типов заданий используются в обоих курсах: choice, fill, output, order, bug.
- Новые курсы работают с существующими подсветкой C++, поиском, XP, прогрессом, домашними работами и повторением ошибок.
- Обновлены описания приложения, порядок сборки контента и версия PWA-кэша.
- Добавлены EMBEDDED_GUIDE.md и команда npm run test:embedded.
- Содержание исходных шести курсов, их ID и механизм localStorage не изменены.

## Выполненные проверки

- Сборка всего YAML в www/data/content.js: 8 курсов, 354 урока, 1736 заданий.
- Проверка структуры новых курсов и уникальности ID всех уроков.
- Побайтово эквивалентные данные исходных шести курсов после десериализации (включая ответы и решения).
- Headless Chromium: все 24 новых урока, все 120 правильных ответов, вывод результата 5/5.
- Все 24 домашние работы: ввод кода, чек-лист, открытие решения и подсветка C++.
- Завершение уроков, увеличение XP, сохранение прогресса и домашней работы после перезагрузки.
- Поиск Arduino/ESP32; попадание ошибки в повторение и удаление после правильного ответа.
- Открытие прежнего урока C++; отсутствие JavaScript-ошибок.
- Сетка курсов: desktop 1440 px и mobile 390 px, без горизонтального переполнения страницы каталога.
- PWA: загрузка кэшированных восьми курсов и работа задания ESP32 при отключённой сети.

## Что не проверялось

Сборка APK/EXE, компиляция скетчей компиляторами Arduino/ESP32 и работа на физических платах. Архив — исходный проект с уже собранным веб-контентом. Для прошивки используйте Arduino IDE и точную модель из EMBEDDED_GUIDE.md. CodeLearn не симулятор и не компилятор микроконтроллеров.
