# Arduino и ESP32 — новые курсы CodeLearn

## Запуск приложения

Распакуйте весь архив и откройте `www/index.html`. Дополнительная установка для чтения курсов не нужна. Для PWA и корректной работы service worker используйте локальный сервер (`npm install`, затем `npm run web`) или HTTPS-хостинг. После обновления ранее установленной PWA подключитесь к сети и обновите страницу; новый кэш применяется после активации нового service worker (может потребоваться закрыть прежние вкладки).

Для APK/desktop используются те же файлы `www`. Архив содержит исходный проект, а не готовые APK/EXE. После изменения веб-файлов для Android выполните `npm run android:sync`, затем пересоберите приложение по BUILD_GUIDE.md.

## Arduino

Базовая плата: **Uno R3, ATmega328P**, логические уровни 5 В. Выберите Arduino AVR Boards → Arduino Uno в IDE.

Минимальный набор: USB-кабель с передачей данных, макетная плата, перемычки, LED, резистор 330 Ом, кнопка, потенциометр около 10 кОм. Для I2C нужен модуль, совместимый по напряжению, и подтяжки/согласование уровней по его документации.

| Узел | Подключение к Uno R3 |
|---|---|
| Встроенный LED | LED_BUILTIN (D13) |
| Внешний PWM LED | D9 → 330 Ом → анод LED; катод → GND |
| Кнопка | D2 → кнопка → GND, INPUT_PULLUP |
| Потенциометр | Крайние выводы 5V/GND, движок A0 |
| I2C | A4/SDA, A5/SCL, общая GND; питание и уровни по даташиту модуля |

Программа: старт и GPIO → ADC/PWM/millis → дребезг/Serial/I2C → прерывания/EEPROM/светильник. В обычных уроках Serial — 9600 бод.

## ESP32

Базовая плата: **ESP32-WROOM-32 DevKit**, классический ESP32; framework **Arduino-ESP32 3.x**. Дополнительный URL менеджера плат Arduino IDE:

```
https://espressif.github.io/arduino-esp32/package_esp32_index.json
```

Пакет: esp32 by Espressif Systems; для указанной универсальной платы — ESP32 Dev Module. Точные параметры flash и USB выбирайте по своей плате. Скорость Serial — 115200 бод.

| Узел | Подключение к ESP32-WROOM-32 DevKit |
|---|---|
| LED/PWM | GPIO18 → 330 Ом → анод LED; катод → GND |
| Кнопка | GPIO19 → кнопка → GND, INPUT_PULLUP |
| Потенциометр/ADC1 | Крайние выводы 3V3/GND, движок GPIO34 |
| Wi-Fi | Для station нужна сеть 2,4 ГГц |

GPIO34…39 — только входы без внутренних подтяжек. GPIO6…11 обычно заняты flash. Не используйте загрузочные пины, не изучив схему платы. **GPIO не выдерживают 5 В.**

Программа: настройка/GPIO/ADC → LEDC/Wi-Fi/HTTP → MQTT/BLE/deep sleep → NVS/FreeRTOS/Wi-Fi панель. LEDC использует `ledcAttach(pin, hz, bits)` и `ledcWrite(pin, duty)` — API ядра 3.x.

### Сеть и библиотеки

- WiFi, WebServer, Preferences, BLE и FreeRTOS входят в выбранный пакет ESP32.
- MQTT требует **PubSubClient by Nick O’Leary** и свой доступный локальный брокер. Замените адрес 192.168.1.10 на адрес брокера, задайте уникальный client ID.
- `YOUR_SSID` и `YOUR_PASSWORD` — заглушки, данные подставляются только локально. Не публикуйте пароль.
- HTTP-пример создаёт сеть `CodeLearn-ESP32` с учебным паролем `learn-esp32`.
- Итоговый проект создаёт `CodeLearn-Lamp` с учебным паролем `learn-lamp`. Эти пароли нужно заменить перед использованием вне учебного теста.
- Подключитесь к точке доступа и откройте напечатанный `softAPIP()` по HTTP. Интернет в этой сети не предоставляется. Телефон может предлагать переключиться на мобильную сеть — для теста останьтесь на Wi-Fi ESP32.
- HTTP и MQTT/1883 в курсе без TLS. Только доверенная изолированная сеть, без проброса портов в Интернет. Для реального устройства нужна отдельная защита, аутентификация и проверка сертификатов.
- BLE-пример — read-only характеристика без настроенной защиты доступа. Не передавайте секреты.

## Ограничения и проверка оборудования

CodeLearn автоматически проверяет ответы на учебные задания, но не выполняет C++ и не имитирует электронику. Домашняя работа проверяется пользователем через Arduino IDE и чек-лист. Учебное решение не заменяет проверку распиновки, даташита и фактического подключения.

Примеры рассчитаны на указанные платформы. В рамках обновления проверяется структура контента и работа интерфейса; прошивка и электрическое поведение на физических платах не проверены. Перед использованием скомпилируйте конкретный скетч для своей платы. Не подключайте моторы, реле или сетевые приборы напрямую к GPIO.
